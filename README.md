# Get-it

Aplicacao web de anotacoes feita com Flask e SQLite.

## Funcionalidades

- criar anotacoes;
- listar anotacoes;
- editar anotacoes;
- excluir anotacoes;
- favoritar e desfavoritar anotacoes;
- mostrar anotacoes favoritas primeiro.

## Como iniciar

Instale o Flask:

```powershell
py -m pip install flask
```

Inicie o servidor:

```powershell
py servidor.py
```

Abra no navegador:

```text
http://127.0.0.1:5000
```

O arquivo `banco.db` e criado automaticamente na primeira execucao.
